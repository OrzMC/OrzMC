# 隐私政策 / Privacy Policy

> 本页是 OrzMC（`orzmc` CLI 与 OrzMC 应用）的隐私政策。**单一事实源**：父仓库 `docs/compliance/privacy.md`，
> 由 `scripts/sync_compliance.py` 生成到官网页面。最后更新：2026-10-16。

OrzMC 是**开源、非商业**的 Minecraft: Java Edition 启动与运维工具。我们**尽可能不收集任何数据**。

## 我们收集什么

**不收集**。OrzMC 没有账号系统、没有遥测、没有分析、也没有自建后端服务器。我们不收集你的账号密码、邮箱、设备标识或使用行为。

## 你设备上的本地数据

OrzMC 只在你自己的设备上读写以下数据，**不会上传给我们**：

- **游戏文件**：客户端 / 服务端核心、资源、库等，下载自 Mojang 官方 CDN。
- **配置与缓存**：游戏根目录（默认 `~/minecraft`）下的版本、缓存与配置。
- **授权令牌（仅当你使用 `--auth`）**：微软设备码登录得到的令牌存放在本机状态目录的 `auth.json`，权限 `0600`（属主可读写）。
  我们不接触这些令牌；它们只在本机用于启动游戏。

## 第三方

使用本工具时可能直接与以下第三方交互，其各自的服务条款与隐私政策适用：

- **Microsoft**（登录授权，设备码流程）
- **Mojang / Minecraft**（游戏文件与档案）
- **GitHub**（发布下载与自升级）

## 数据删除

- 卸载工具：`orzmc self-uninstall`（默认保留游戏数据；加 `--remove-root` 一并删除）。
- 删除授权令牌：删除本机状态目录下的 `orzmc/auth.json`（或直接删除整个状态目录）。
- 删除游戏数据：删除游戏根目录（默认 `~/minecraft`）。

## 儿童

OrzMC 是通用的工具软件，并非面向儿童设计或营销；我们也不会有意收集儿童的任何数据。

## 变更

本政策如有更新，将随仓库提交更新（本页顶部标注最后更新日期）。
