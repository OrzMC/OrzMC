# OrzMC 隐私政策 / Privacy Policy

> 本政策由 **OrzMC 组织**（下称「我们」）制定，统一适用于我们维护的全部开源项目与官方渠道。
> **单一事实源**：父仓库 `docs/compliance/privacy.md`，由 `scripts/sync_compliance.py` 生成到官网页面。
> 最后更新：2026-10-16。

OrzMC 是一个**开源、非商业**的 Minecraft 社区组织。我们把「尽可能不收集数据」作为默认设计原则：不设账号体系、不做用户画像、不投放广告、不买卖数据。

## 一、适用范围

本政策适用于 OrzMC 组织维护的：

- **官方网站** —— `https://orzmc.jokerhub.cn`（Hugo 静态站，托管于 GitHub Pages）；
- **开源软件** —— `orzmc` 命令行工具（Python / Swift 两种实现）、OrzMC 桌面与移动应用，以及面向 PaperMC 服务端的插件、世界备份与区块清理工具等（统称「本软件」）；
- **协作渠道** —— 我们在 GitHub 上的组织主页与各代码仓库（Issues / Pull Requests / Releases）。

其它第三方服务，以及你在使用过程中自行选择的平台，不在本政策范围内。

## 二、我们不会做的事

- 不要求注册、不设账号，不把你的邮箱、手机号等作为使用前提；
- 不集成遥测、埋点或崩溃上报，不做使用行为分析；
- 不投放广告，不向任何第三方出售、出租或交易你的数据；
- 不跨站点追踪你，不建立个人画像。

## 三、开源软件（客户端 / 服务端工具 / 插件）

本软件在**你自己的设备或服务器**上运行，我们无法访问其中数据。

- **本地文件**：客户端 / 服务端核心、资源与库等下载自 Mojang 官方 CDN；版本、缓存与配置写入游戏根目录（默认 `~/minecraft`）。这些数据始终留在本机。
- **授权令牌（仅当你使用 `--auth`）**：经微软设备码流程登录后，令牌保存在本机状态目录的 `auth.json`，文件权限 `0600`（仅属主可读写）。我们接触不到这些令牌，它们只在本机用于启动游戏。
- **网络请求**：软件会直接访问 Mojang / Microsoft 官方接口获取游戏文件与登录授权，并从 GitHub Releases 检查更新、下载产物；这些请求由对应服务按其隐私政策处理。
- **插件与工具**：运行在你自有的服务器上，产生的日志与数据完全由你掌控。
- **卸载与删除**：`orzmc self-uninstall`（默认保留游戏数据，加 `--remove-root` 一并删除）；删除令牌即删除状态目录下的 `orzmc/auth.json`。

## 四、官方网站

官网是纯静态页面，不设账号、评论或表单，也不使用用于追踪的 Cookie 或广告 SDK。为统计访问量与展示实时信息，页面会加载以下**第三方**资源：

- **访问统计（不蒜子 / Busuanzi）**：浏览器加载第三方脚本 `busuanzi.ibruce.info`，用于统计总访问量（PV）与访客数（UV）。该服务可能记录 IP、User-Agent 等信息用于去重计数；**我们只能看到聚合后的计数，无法关联到具体个人**。它可能写入 Cookie 或本地存储。
- **服务器实时状态（api.mcstatus.io）**：展示服务器状态时，页面会由你的浏览器直接请求 `api.mcstatus.io`；作为任意 HTTP 请求，该服务可看到请求来源 IP。
- **玩家头像（mc-heads.net）**：展示在线玩家列表时按需加载 `mc-heads.net` 的头像；Minecraft 玩家名与 UUID 本身是公开信息。

> 上述第三方可能写入 Cookie 或处理请求元数据，其行为受各自隐私政策约束；我们不会把第三方数据与你的身份进行关联。若你不希望被统计，可启用浏览器隐私模式、内容拦截器，或直接阻止相应域名。

## 五、第三方服务

使用我们的项目时，可能直接与下列第三方交互，请一并阅读其隐私政策：

- **Microsoft / Mojang** —— 账户登录与游戏文件；
- **GitHub** —— 代码托管、Issue / PR 协作、Release 下载；
- **不蒜子 Busuanzi** —— 官网访问统计；
- **api.mcstatus.io / mc-heads.net** —— 服务器状态与玩家头像；
- **支付宝等支付平台** —— 仅当你自愿赞助时；支付信息由支付平台处理，我们不收集。

## 六、数据安全与保留

- 我们**不运营用于存储你个人信息的自建后端**，因此不存在由我们集中保存的个人数据库。
- 软件在本机产生的数据由你掌控；第三方服务的数据保留遵循其各自政策。

## 七、你的权利

由于我们不收集可识别你身份的个人数据，通常无从「查询 / 更正 / 删除」——相关数据要么只存在于你的设备，要么由第三方按其政策管理。若你对某项处理有疑问，欢迎通过下方渠道与我们联系。

## 八、儿童

本软件与网站是通用工具与公开内容，并非面向儿童设计或营销，我们也不会主动收集儿童的任何数据。

## 九、政策变更

本政策如有更新，将随代码仓库提交一并发布，并在本页顶部标注最后更新日期。

## 十、联系我们

如对本政策或数据处理有任何疑问，请通过 GitHub 组织主页发起 Issue 或 Discussion：[github.com/OrzMC](https://github.com/OrzMC)。
